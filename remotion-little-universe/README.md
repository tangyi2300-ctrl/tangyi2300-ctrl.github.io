# 唐懿的小宇宙 · Remotion 视频

30 秒个人介绍视频，1920×1080、30fps、H.265，包含原创合成纯音乐。

- [下载第九版视频 MP4](https://github.com/tangyi2300-ctrl/tangyi2300-ctrl.github.io/releases/download/little-universe-v9/tang-yi-little-universe-v9.mp4)
- [下载完整 Remotion 工程 ZIP（源码、照片、短片、配乐）](https://github.com/tangyi2300-ctrl/tangyi2300-ctrl.github.io/releases/download/little-universe-v9/tang-yi-little-universe-v9-source.zip)
- [查看发布页](https://github.com/tangyi2300-ctrl/tangyi2300-ctrl.github.io/releases/tag/little-universe-v9)

解压工程包，在目录中运行：

```sh
npm ci
npm start
```

在 Remotion Studio 选择 `LittleUniverse`。执行 `npm run render` 可重新导出视频。工程包内含完整 README 与配乐生成脚本。

第九版使用海边落日照片收尾；拼贴页采用最新拼豆展示柜照片；手作页展示微缩花园、小熊雪景球及串珠挂饰。

照片、肖像、视频与音乐素材的公开展示不等于授予第三方复用许可。
