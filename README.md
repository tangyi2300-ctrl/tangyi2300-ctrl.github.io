# 唐懿 Tang Yi · 我的小世界

**个人网站：https://tangyi2300-ctrl.github.io/**

结合唐懿的飞书自我介绍、个人照片及介绍视频制作的个人网站。视觉参考 [Husna Jakeer 的个人作品集](https://husnajakeer.github.io/personal-portfolio/)，使用奶油色背景、鼠尾草绿与蜜桃粉配色、圆润照片边框与醒目的姓名排版；页面为独立实现，未复制参考站点的代码或个人素材。

## 内容和功能

- 个人介绍、兴趣和手工作品
- 拼豆与其他手作分类筛选，照片放大预览
- 猫咪日常与 75 秒自我介绍视频
- 深浅色模式切换并记住选择
- 响应式导航、键盘访问和减少动态效果支持
- 邮箱、电话、抖音、小红书及 GitHub 链接

## 本地预览

在此目录运行 `python3 -m http.server 8080`，打开 http://localhost:8080。

HTML、CSS、JavaScript 静态网站，无第三方运行时依赖。GitHub Pages 从 `main` 分支根目录自动发布。图片与影片保存在仓库中，不依赖飞书登录。

个人照片、视频及手工作品图片未经许可请勿转载。
