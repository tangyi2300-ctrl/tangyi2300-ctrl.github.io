# 唐懿 · 个人网站

一个关于好奇心、旅行、美食、小猫与手工创作的个人画廊。

在线访问：https://tangyi2300-ctrl.github.io/

## 内容与功能

- 自我介绍与真实个人照片
- 拼豆、扎染及手作展示，支持分类筛选和图片放大
- 75 秒自我介绍视频
- 猫咪日常、邮箱与社交链接
- 手机布局、键盘操作与减少动态效果支持

## 本地预览

在源码目录执行 `python3 -m http.server 8080`，访问 http://localhost:8080。

网站为 HTML / CSS / JavaScript 静态页面，无需安装依赖。GitHub Pages 使用 main 分支根目录发布。
